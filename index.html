A RESEARCH CONTRACT YOU CAN FOLLOW

  1. ObserveSignal at close t
  2. ExecuteNext common close
  3. AccountCosts, cash & holdings
  4. InspectLedger + validation

Hypothetical research. Daily adjusted prices. No live trade execution. Results depend on the selected data and assumptions.

Explore the engineering decisions +

Separate the model from the interface. Portfolio calculations and the backtest engine run without UI or network calls, making deterministic tests possible.

Make timing and accounting explicit. Decisions execute at the next common close; holdings drift between rebalances, costs are self-funded, and unused capital stays in cash.

Distinguish fitted results from later evaluation. Walk-forward allocation re-estimates weights on trailing data before evaluating later observations. This does not remove selection or survivorship bias.

Current default branch: single-node. Distributed execution and Apache Iceberg integration remain roadmap work.

Explore the engineering decisions +

Preserve query semantics. Pushdown is conservative: DataFusion rechecks supported predicates locally. String ordering is excluded because PostgreSQL collation can disagree with Arrow ordering.

Cache without changing representation. Shared Arrow record batches avoid turning query results into display strings. The current cache is bounded by entry count, with TTL and LRU eviction.

Keep experimental work visible. File-based change events invalidate the cache today. Agent interfaces, broader ADBC integration, and native CDC foundations are a separate draft preview; they are not a production release.
